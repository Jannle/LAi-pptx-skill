# 风格与原生版式

这是从 HTML 视觉系统到 PPTX 的设计改编，不是浏览器截图导出。画布固定为 16:9，文字与流程保持原生编辑能力。一份文稿选择一种 `style` 和与之匹配的 `theme`。

## 三套风格

| style | 核心规则 | 可选 theme |
|---|---|---|
| `magazine` | 衬线标题、无衬线正文、等宽元信息，暖纸色与墨色，细线和留白 | `ink`（默认）、`indigo`、`forest`、`kraft`、`dune` |
| `swiss` | 左对齐、单一锚点色、严格几何排列、强字号反差；不使用渐变、圆角或阴影 | `ikb`（默认）、`lemon`、`lime`、`orange` |
| `huawei` | 白灰底、红色强调、左上标题锚点、右上品牌文字位、左下页码；大面积红色用于封面/章节/结尾 | `classic-red`（默认）、`executive`、`cloud-tech` |

令牌见 `themes.json`。它们保留上游的主要 paper/ink/accent；PPTX 的辅助文本与线条色按原生输出需要整理。黄色、绿色及橙色强调底使用深色字；这些主题在浅底上的强调文字也改用深色，提高可读性。橙色对比文字因此与上游白字令牌有所不同。

## 字体

默认正文为 `Noto Sans CJK SC`，等宽标注为 `Noto Sans Mono CJK SC`；杂志风标题为 `Noto Serif CJK SC`，其余标题为 `Noto Sans CJK SC`。这是一组便于跨平台安装的 CJK 字体替代，不声称和原网页的 Playfair / Inter / CDN 字体逐字形一致。

通过顶层 `fonts.heading`、`fonts.body`、`fonts.mono` 改为目标机器已安装字体。例如 Windows 可按需选择 Microsoft YaHei，但必须重新检查换行。PPTX 不嵌入字体。

## 14 类版式

所有版式都使用 `layout` 字段。下表是语义迁移关系，不是原 HTML 布局 ID 的完整实现承诺。

| layout | 用途 | PPTX 实现与来源关系 |
|---|---|---|
| `cover` | 封面 | 原生大标题/副标题，改编自三套风格封面 |
| `agenda` | 目录 | 编号文本行；企业风有红色目录侧栏 |
| `section` | 章节 | 章节编号与大标题，替代网页章节幕封 |
| `statement` | 观点/引言 | 大号正文与可选出处，来自杂志引言及 Swiss statement 思路 |
| `bullets` | 要点 | 1–5 条原生文本，适合简洁说明 |
| `compare` | 双栏对比 | 等宽左右栏，各自标题与要点；不是图片对比卡 |
| `kpi` | 大字数字 | 1–3 项数值文本、标签及解释；不同单位不强行画成可比柱形 |
| `chart` | 数据比较/趋势/构成 | 原生条形、柱形、折线、环形图与嵌入数据 |
| `table` | 结构化数据 | 原生表格，不把文字做成 SVG 或图片 |
| `process` | 顺序流程 | 2–4 步原生文字、线条与箭头；并非上游所有 loop/组织图布局 |
| `timeline` | 阶段进度 | 2–4 个日期、节点与解释 |
| `image` | 单图或图文 | PNG/JPEG 图片对象 + 可编辑正文/图注 |
| `image_grid` | 图片网格 | 2–3 张等宽图片槽位 + 可编辑图注 |
| `closing` | 结尾 | 大标题、收束文字与联系方式 |

上游瑞士版式存在旧 P 编号与 canonical S 编号的差异。此包使用自己的语义名，不把近似布局错误标为某个完全相同的 S/H 版式。复杂的 H37–H42 组织协议等内容可按任务另行扩展，不能声称已经全部实现。

## 内容与检查

- 原始事实、单位、来源必须保留；示例数字要标明示例。
- 每页优先一项清晰任务。放不下时分页，而不是隐藏、裁掉必需内容或缩为小字。
- 图文页图片默认 `contain`，证据型截图不得为了填满槽位裁掉关键信息。使用 `cover` 前确认允许裁剪。
- 商标、用户截图和证据图保留原始比例与真实性。不要自动重绘截图文字或替换品牌。
- 保持页标题与正文的左边界、同级元素尺寸、图注和页码一致。引用放入演讲者备注，不把软件自检记录塞进幻灯片。
- 静态渲染用于验排，PowerPoint 放映用于动画验收；二者不能互相替代。
